# Twinkly Pro for Home Assistant

**Twinkly Pro** — продвинутая кастомная интеграция для умных гирлянд **Twinkly** в Home Assistant со встроенной веб-панелью **Twinkly Studio**.

Устанавливается целиком через HACS и работает на любых инсталляциях Home Assistant (OS, Supervised, Container, Core).

---

## Возможности

1. **Умная группировка гирлянд (`Master` / `Slave` Sync)**
   - Автоматическое определение созданных групп (`group_uid`) и ролей устройств.
   - Маршрутизация команд управления на `Master`-контроллер без рассинхронизации ведомых гирлянд.
   - Создание и объединение новых групп прямо из веб-панели Home Assistant.

2. **Полное управление плейлистами**
   - Чтение, редактирование, переключение текущего эффекта и настройка таймингов (`duration`).
   - Drag-and-Drop редактор очереди воспроизведения в панели **Twinkly Studio**.

3. **Twinkly Music & Светомузыка**
   - Управление режимом `music`, выбор музыкальных драйверов и наборов пресетов (`/xled/v1/music/...`).
   - Регулировка чувствительности микрофона и стриминг эквалайзера по UDP (Real-Time режим).

4. **Визуальный генератор эффектов и 2D/3D маппинг**
   - Считывание реальных физических координат каждого светодиода (`/xled/v1/led/layout/full`).
   - Встроенный 2D/3D предпросмотр гирлянды на интерактивном Canvas.
   - Генератор процедурных анимаций (градиенты, бегущие волны, плазма, радуга, мерцание, эквалайзер).
   - Мгновенный Live-стриминг по UDP (порт `7777`) или компиляция в бинарный формат `.movie` с загрузкой во флеш-память гирлянды (`POST /xled/v1/movies/full`).

5. **Облачная и локальная библиотека эффектов**
   - Локальное хранилище эффектов на диске Home Assistant (без ограничений встроенной памяти контроллера).
   - Опциональная синхронизация с облаком Twinkly.

## Установка через HACS

1. Откройте **HACS** в Home Assistant -> **Интеграции** -> меню в правом верхнем углу -> **Пользовательские репозитории**.
2. Добавьте URL репозитория: `https://github.com/Kuresha-HA/Twinkly_Pro` с категорией **Интеграция** (`Integration`).
3. Найдите **Twinkly Pro** и нажмите **Скачать**.
4. Перезапустите Home Assistant.
5. Перейдите в **Настройки** -> **Устройства и службы** -> **Добавить интеграцию** -> **Twinkly Pro** (или подтвердите автоматически найденные через Zeroconf гирлянды).

## Сущности и сервисы

### Создаваемые сущности (для каждого контроллера / группы):
- `light`: Включение/выключение, яркость, RGB/RGBW цвет, быстрый выбор эффекта из памяти или режима.
- `select`:
  - Режим работы (`off`, `color`, `movie`, `playlist`, `music`, `rt`, `demo`).
  - Активный эффект (Movie).
  - Текущий элемент плейлиста.
  - Музыкальный драйвер / пресет.
- `number`: Чувствительность микрофона / скорость эффекта.
- `button`: Следующий / предыдущий эффект плейлиста, синхронизация группы.
- `sensor`: Роль в группе (`Standalone`, `Master`, `Slave`), `group_uid`, свободная память эффектов, количество LED, версия прошивки.

### Сервисы (`Actions`):
- `twinkly_pro.set_mode` — переключение режима работы гирлянды.
- `twinkly_pro.upload_generated_movie` — генерация и заливка эффекта во флеш-память гирлянды.
- `twinkly_pro.set_playlist` — запись нового плейлиста с таймингами.
- `twinkly_pro.start_rt_effect` / `twinkly_pro.stop_rt_effect` — запуск и остановка потокового Real-Time эффекта по UDP.
- `twinkly_pro.configure_sync_group` — объединение нескольких гирлянд в синхронную группу (`Master` + `Slave`) или роспуск группы.
